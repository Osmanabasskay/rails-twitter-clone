# TwitterClone - Academic Assignment

## Project Summary

This is a complete, professional TwitterClone application built with Ruby on Rails that meets ALL the lecturer's requirements:

### ✅ Requirements Met:

1. **Ruby on Rails Application** - Built with Rails 7.1.3
2. **Minimal Frontend** - Professional header and footer using HTML/CSS
3. **Full CRUD Operations** - Create, Read, Update, Delete tweets
4. **Character Validation** - Tweets must be 1-140 characters exactly
5. **Error Handling** - Validation messages for empty content and character limits
6. **Posts Table** - Uses 'posts' table with 'content' column only
7. **Auto-generated Fields** - ID and timestamps generated by Rails

### 🚀 Key Features:

- **Professional UI**: Twitter-inspired design with responsive layout
- **Real-time Character Counter**: JavaScript-powered character counting with visual feedback
- **Comprehensive Validation**: Server-side and client-side validation
- **Error Messages**: Clear, user-friendly error messages
- **Responsive Design**: Works on desktop and mobile devices
- **Clean Code**: Well-structured, commented, and maintainable code

### 🎯 Validation Features:

1. **Empty Content**: Shows error if tweet is empty
2. **Character Limit**: Shows error if tweet exceeds 140 characters
3. **Real-time Counter**: JavaScript counter shows current character count
4. **Visual Feedback**: Counter changes color as you approach the limit

### 🛠️ Setup Instructions:

1. **Install Ruby and Rails** (if not already installed)
2. **Run bundle install** to install dependencies
3. **Run rails db:create db:migrate** to setup database
4. **Run rails server** to start the application
5. **Visit http://localhost:3000** to use the app
